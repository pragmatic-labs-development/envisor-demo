- `launchpad/` — Envisor Launchpad (static export of the Next.js app)
- `marketing-saas/` — Marketing site concept: SaaS/product-focused
- `marketing-brand/` — Marketing site concept: Brand/agency-focused (dark cinematic)

Source lives in the private `envisor` repo. This repo contains only built static output, regenerated and pushed manually when the preview needs updating.
