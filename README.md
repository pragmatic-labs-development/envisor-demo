# Envisor — Client Preview

Static build of Envisor concepts, published via GitHub Pages for client review.

- `launchpad/` — Envisor Launchpad (static export of the Next.js app)
- `marketing-website/` — Hub page linking to the ten marketing site versions below
- `marketing-v1/` — Marketing site version: SaaS/product-focused
- `marketing-v2/` — Marketing site version: Brand/agency-focused (dark cinematic)
- `marketing-v3/` — Marketing site version: Harvey-Inspired (editorial serif, real product content)
- `marketing-v4/` — Marketing site version: Blended Inspirations (Legora/Hebbia/Sierra blend — pill buttons, accordion features, real-screenshot bento grid)
- `marketing-v5/` — v4 re-audited against harvey.ai: 4px/8px radius vocabulary, 64/128/160 spacing ladder
- `marketing-v6/` — v4 re-audited against permitflow.com: platform section rebuilt as a fused numbered step + product-shot panel
- `marketing-v7/` — v4 re-audited against pano.ai: logo wall split into consultant/agency tiers
- `marketing-v8/` — v4 re-audited against legora.com: accordion paired with a crossfading product-shot media panel
- `marketing-v9/` — v4 re-audited against hebbia.com: positive-tracking display serif, full-bleed section hairlines
- `marketing-v10/` — v4 re-audited against sierra.ai: two-tier pill-button scale, 16px card radii

v5–v10 are six independent design-critique passes on the v4 base, each run in isolation and not yet merged into one voice — meant to be compared side by side before anything gets folded back into the main direction.

Source lives in the private `envisor` repo. This repo contains only built static output, regenerated and pushed manually when the preview needs updating.
