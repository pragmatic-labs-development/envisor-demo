# Envisor — Client Preview

Static build of five Envisor concepts, published via GitHub Pages for client review.

- `launchpad/` — Envisor Launchpad (static export of the Next.js app)
- `marketing-website/` — Hub page linking to the four marketing site versions below
- `marketing-v1/` — Marketing site version: SaaS/product-focused
- `marketing-v2/` — Marketing site version: Brand/agency-focused (dark cinematic)
- `marketing-v3/` — Marketing site version: Harvey-Inspired (editorial serif, real product content)
- `marketing-v4/` — Marketing site version: Blended Inspirations (Legora/Hebbia/Sierra blend — pill buttons, accordion features, real-screenshot bento grid)

Source lives in the private `envisor` repo. This repo contains only built static output, regenerated and pushed manually when the preview needs updating.
